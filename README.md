# Introduction
This project analyzes a Clinvar VCF file to identify rare genetic variants and the diseases associated with them. 
VCF files contain information about genetic variants, including chromosome position, reference and alternate alleles,
and additional details stored stored in the INFO column. In this assignment, the program focuses on two INFO fields:
AF_EXAC, which gives the allele frequency of a variant in the ExAC database, and CLNDN, which lists the disease names 
associated with the variant.
